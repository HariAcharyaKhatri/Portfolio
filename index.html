About Hari

The Mind Behind the Code

Bridging the gap between hardware memory constraints and responsive user experiences.

I am Hari Khatri, a Bachelor of Computer Applications (BCA) student at Adarsh College of Professional Studies, Abu Road (affiliated with MLSU Udaipur), residing in the scenic hill town of Mount Abu, Rajasthan.

My development journey is driven by a deep curiosity about how software works beneath the surface. Rather than relying exclusively on high-level frameworks, I began by mastering C and C++, exploring direct memory allocation, pointer arithmetic, data structures, and algorithmic state machines.

Today, I channel that foundational knowledge into building complete products: from rich interactive web apps like Silicon Dynasty (a deep PC empire simulation built with React 19 & TypeScript) and CALIGO (a browser crime MMORPG with client-side state) to native Java IDE tooling and complex discrete mathematical game engines.
